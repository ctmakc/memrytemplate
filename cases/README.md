# Active cases

One continuing objective = one canonical case.

Path convention:

`cases/<domain>/<project-or-client>/<YYYY-MM-DD>-<short-objective>.md`

Examples of domains: `projects`, `sales`, `marketing`, `operations`, `design`, `learning`.

Use `_templates/case.md`. Search before creating. Update instead of duplicating.

Active cases are current-state snapshots. If a file becomes a transcript, compact it.
